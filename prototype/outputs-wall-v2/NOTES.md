# Open-Lens 成品墙 v2 — 变体说明

入口 `index.html`,纯单文件无依赖。假数据 68 张(IMG_4063 起,seed 固定可复现)。
快捷键:变体 C 内 `←/→` 翻页;任意变体下 `↑/↓` 或 `⇧←/⇧→` 切变体;A/B 内 `←/→` 也切变体。URL `?variant=A/B/C` 保持,刷新恢复。

## 变体 A 「审计台」
回答子问题 1(列表露出什么):全字段表格 —— 缩略图/ar/偏差px/edited/耗时/labeledAt/状态色块,列头排序+筛选,赌「数据工作者要的是 Excel 式全信息扫视,排序和筛选比缩略图大更重要」。

## 变体 B 「双栏巡视」
回答子问题 3(导航不迷路):顶部全局迷你点阵+左栏缩略图流双定位,右栏常驻详情(原图/成品左右对比),无模态、选中态跨视图共享,赌「master-detail 的零跳转成本胜过表格密度,位置感靠点阵+当前白框」。

## 变体 C 「胶片台」
回答子问题 2(如何确信这张没问题):单张拉满 —— 大图双框叠加、可拖绿把手、ar 大字(离群变黄)、原图+成品预览同屏,键盘逐张过,赌「确信感来自一次只看一张、所有证据同屏,密度让位给专注力」。
